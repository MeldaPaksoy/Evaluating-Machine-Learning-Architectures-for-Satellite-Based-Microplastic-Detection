# Evaluating-Machine-Learning-Architectures-for-Satellite-Based-Microplastic-Detection
Machine learning pipeline for marine microplastic detection using MODIS-Aqua satellite proxies (SST, Chlorophyll-a, Kd_490) and in-situ observations.
## Dataset Access
The processed dataset is hosted on Kaggle:
[Kaggle Dataset Repository]([https://huggingface.co/datasets/KULLANICI_ADIN/DATASET_ADIN](https://www.kaggle.com/datasets/meldapaksoy/dataset-with-diffuse-attenuation-coefficient))
